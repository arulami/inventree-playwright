# InvenTree Parts — Parts CRUD (API)

Requirements: [requirements/parts-api.md](../../requirements/parts-api.md) · [requirements/parts.md](../../requirements/parts.md) · Test data: [test-data/parts-environment.md](../../test-data/parts-environment.md) · Legend: [README](../../../README.md#legend)

Endpoints: `/api/part/` and `/api/part/{id}/` (API version 560). `<new part>` = a part created by the case's own pre-condition with `POST /api/part/` as `engineer`; deactivate (`PATCH active=false`) and delete it after the case.
